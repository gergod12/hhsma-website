# 線上簽到頁 `checkin/`

網址：`https://healthselfmanage.org.tw/checkin/`

理監事從 LINE 點開連結，點自己的名字即完成簽到。簽到資料寫進 Google 試算表
「第一屆第三次理監事聯席會議 線上簽到單」的「簽到紀錄」工作表。

## 第一次啟用（只做一次，約 5 分鐘）

1. 打開試算表「第一屆第三次理監事聯席會議 線上簽到單」。
2. 上方選單「擴充功能」→「Apps Script」。
   （手機沒有這個選單。改用手機瀏覽器開 https://script.google.com ，切到「電腦版網站」，
   按「新專案」；程式裡已填好試算表 ID，獨立專案一樣能寫入。）
3. 把編輯器裡原本的內容全部刪掉，貼上本資料夾 `apps-script.gs` 的全部內容，按儲存（磁片圖示）。
4. 右上角「部署」→「新增部署作業」→ 左側齒輪選「網頁應用程式」。
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 按「部署」，第一次會要求授權：選自己的 Google 帳號 → 進階 → 前往（不安全）→ 允許。
6. 複製畫面上的「網頁應用程式網址」（開頭是 `https://script.google.com/macros/s/…/exec`）。
7. 把這個網址貼進 `config.js` 的 `scriptUrl: ""` 引號中，推上 GitHub 即可。

## 每次開會前

只改 `config.js` 的 `meeting` 區塊：`id`（建議用日期）、`title`、`time`、`place`。
同一個 `id` 之下每個人只會記錄一次，換 `id` 就是新的一場會議。

## 名單

`config.js` 的 `groups` 與官網「組織架構」同步；人事異動時兩邊一起改。
名單外的列席人員可按「其他列席人員」自行輸入姓名。

## 修改 Apps Script 之後

改過 `apps-script.gs` 要重新「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」→ 部署，
網址不會變。
